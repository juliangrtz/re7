# Code Of Conduct

This should be a useful, welcoming place for people working on BioRand 7, RE7 modding, reverse engineering, testing, documentation, and randomizer design.

## Expected Behavior

- Be respectful and patient.
- Assume good intent, but be clear when something is unsafe, incorrect, or likely to cause softlocks.
- Keep bug reports factual and reproducible.
- Credit prior work such as publicly available mods on NexusMods or public Cheat Engine tables.
- Explain sources when sharing reverse-engineering findings.
- Respect legal boundaries around game files, private credentials, and copyrighted assets.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Publishing someone else's private information.
- Sharing pirated game assets, full vanilla PAKs, or private credentials.
- Repeatedly derailing issues or pull requests.
- Bad-faith behavior that makes maintainers or contributors less able to work on the project.

## Enforcement

Maintainers may edit, hide, lock, or delete comments; close issues or pull requests; or block users when needed to keep the project healthy.

If you need to report conduct concerns, contact a maintainer through the most private available project channel. If no private channel is available, open a minimal public issue asking for maintainer contact without including sensitive details.
